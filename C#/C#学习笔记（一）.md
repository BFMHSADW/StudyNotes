## 二进制与十进制的转换

- 计算机使用二进制来表示和处理数据，而人类习惯使用十进制
- 二进制是以2为基数的数制，只有0和1两种数字
- 十进制是以10为基数的数制，包含0到9共十种数字

1. 二进制数转换为十进制的方法是将每一位的值乘以对应的2的幂次方，然后将结果相加（位权从右到左依次为 2^0、2^1、2^2……）
  
    **例如**，二进制数`1101`转换为十进制数的计算过程如下：
  
    ```csharp
      1*2^3 + 1*2^2 + 0*2^1 + 1*2^0 = 8 + 4 + 0 + 1 = 13
    ```
  
    **结论**：将结果相加得到十进制数`13`

2. 十进制整数部分转换为二进制数的方法是不断除以2，记录余数，直到商为0，然后将余数倒序排列
  
    **例如**，十进制数`13`转换为二进制数的计算过程如下：

    ```csharp
      13 / 2 = 6 余 1
      6 / 2 = 3 余 0
      3 / 2 = 1 余 1
      1 / 2 = 0 余 1
    ```

    **结论**：将余数倒序排列得到二进制数`1101`

3. 十进制小数部分转换为二进制数的方法是不断乘以2，记录每次得到的整数部分（0或1），直到小数部分为0或达到所需的精度。然后，将整数部分顺序排列（即从第一次得到的整数开始，从左到右排列）
  
    **例如**，十进制数`0.375`转换为二进制的计算过程如下：
  
    ```csharp
      0.375 * 2 = 0.75  整数部分为0
      0.75 * 2 = 1.5    整数部分为1
      0.5 * 2 = 1.0     整数部分为1
    ```

    **结论**：将整数部分顺序排列得到二进制数`0.011`

4. 负数十进制转换为二进制数时，通常使用补码表示,补码的计算方法是将整数的绝对值转换为二进制，然后取反加1

    **例如**，十进制数`-13`的补码计算过程如下：

    ```csharp
      |-13| = 13                      -13的绝对值为13
      13 → 00001101（原码）            计算绝对值13的二进制原码（8位表示）
      00001101 → 11110010（反码）      对原码取反得到反码（符号位不变）
      11110010 + 1 = 11110011（补码）  反码加1得到补码
    ```

   **结论**：十进制数`-13`转换为补码为`11110011`

5. **特殊情况**：如果小数部分不能精确转换为二进制，则会进入循环，需要根据精度要求终止计算

    **例如**，十进制`0.2`转换为二进制的计算过程如下：

    ```csharp
      0.2 * 2 = 0.4    整数部分为0
      0.4 * 2 = 0.8    整数部分为0
      0.8 * 2 = 1.6    整数部分为1
      0.6 * 2 = 1.2    整数部分为1
      0.2 * 2 = 0.4 * 2 = 0.8    整数部分为0
      0.8 * 2 = 1.6    整数部分为1
      0.6 * 2 = 1.2    整数部分为1
      0.2 * 2 = 0.4    整数部分为0
      ......
    ```

    **结论**：0.2的二进制是0.001100110011...（循环节0011），写作`0.0(0011)`

- 二进制是计算机唯一能识别和处理的数据形式，所有的数据在计算机内部最终都会转换为二进制进行存储和运算
- 理解二进制的表示和转换方法，有助于更好地理解计算机的工作原理和数据处理过程
- 在实际编程中，我们通常使用高级语言来操作数据，而不需要直接处理二进制表示，但了解其本质对于深入理解计算机科学是非常有帮助的

## 变量和常量

### 变量

#### 什么是变量

- 用于在计算机的内存中存储不同数据类型数值的容器
- 不同的变量类型，可以存储不同类型的值

#### 变量的语法

- 声明变量的基本语法

  ```csharp
    <变量类型> <变量名称>;
    <变量名称> = <变量值>;
  ```

  **简写**

  ```csharp
    <变量类型> <变量名称> = <变量值>;
    int a = 10;  //变量声明时可以直接赋值
  ```

#### 变量的使用

- 必须先声明、后赋值、再使用，不能无中生有
- 注意：局部变量在使用前必须先赋值；类或结构体的字段在声明后会有默认值（例如 `int` 默认为 0），因此两者在初始化要求上不同。

  ```csharp
    int a; // 声明变量
    a = 10; // 赋值变量
    Console.WriteLine(a); // 使用变量
  ```

  **示例**

  ```csharp
    //姓名
    string name = "Lucky"; // 字符串类型
    //年龄
    byte age = 28; // 整数类型
    //性别
    char gender = 'M'; // 字符类型
    //身高
    float height = 5.9f; // 浮点数类型
    //体重
    double weight = 70.5; // 浮点数类型
    //是否已婚
    bool isMarried = false; // 布尔类型

    Console.WriteLine("Name: " + name + ", Age: " + age + "，Gender："+gender+", Height: " + height + ", Weight: " + weight + ", Is Married: " + isMarried );
  ```

- 多个相同类型的变量的声明方式

  ```csharp
    //固定写法
    <变量类型> <变量名称> = <变量值>, <变量名称> = <变量值>, <变量名称> = <变量值>, ......;
  ```

  **示例**

  ```csharp
    int a1 = 80, a2 = 78, a3 = 98; // 声明多个变量
    Console.WriteLine("数学成绩：" + a1 + ",语文成绩：" + a2 + ",英语成绩：" + a3);
  ```

  - 优点：代码更简洁，减少重复代码
  - 注意：只有相同类型的变量才能这样声明

#### 变量的修改

- 变量在声明并赋值后，可以在程序运行过程中修改其值

  ```csharp
    int score = 80; // 声明并初始化变量
    Console.WriteLine("初始分数：" + score); // 输出：初始分数：80
    score = 90; // 修改变量的值
    Console.WriteLine("修改后的分数：" + score); // 输出：修改后的分数：90
  ```

  - 变量的值可以被多次修改
  - 修改时不需要再次声明变量类型，直接使用变量名赋值即可

#### 变量的本质

- 变量在计算机底层是以二进制形式实现的，它的本质是提供了有意义的名称、类型安全和操作语义的数据存储抽象
- 因为数据传递只能通过电信号，计算机的硬件电路只能识别两种状态：通电（1）和断电（0），所以计算机中所有的数据底层都是二进制，由0和1组成
- 1比特（[^Bit]）就是1位数，要么是0，要么是1，为了方便存储和处理数据，计算机将多个比特（Bit）组合在一起，形成更大的存储单位
- 8个比特（Bit）组成1个字节（[^Byte]），我们一般也称1个字节为8位
- 由此可知，1个字节（Byte）最小值为0000 0000（0），最大值为1111 1111（255）

  ```csharp
    Min  0000 0000 = 0
    Max  1111 1111 = 255
  ```

[^Bit]: 比特（Bit）是计算机中最小的数据单位（0或1）
[^Byte]: 字节（Byte）是计算机中最基本的可寻址内存单元

#### 变量类型

- 计算机通过不同数量的字节（Byte）来表示不同类型的数据
  - 无符号整数类型变量`byte`的大小是一个字节，取值范围就是0-255，

    ```csharp
      Min  0000 0000 = 0
      Max  1111 1111 = 255 
    ```

  - 有符号整数类型变量`sbyte`的也是占用一个字节，但它的取值范围是-128到127,其中最高位为符号位，0表示正数，1表示负数

    ```csharp
      Min  1000 0000 = -128 //最高位的1代表负数
      Max  0111 1111 = 127  //最高位的0代表正数
    ```

- 有符号的整数类型，存储一定范围内正负数包括0的变量类型

  | 变量名 | 描述 | 取值范围 | 占用内存 |
  | :-----: | :-----: | :-----: | :-----: |
  | `sbyte` | 8位有符号整数 | -128 到 127 | 1个字节 |
  | `short` | 16位有符号整数 | -32,768 到 32,767 | 2个字节 |
  | `int` | 32位有符号整数 | -2,147,483,648 到 2,147,483,647 | 4个字节 |
  | `long` | 64位有符号整数 | -9,223,372,036,854,775,808 到 9,223,372,036,854,775,807 | 8个字节 |

- 无符号的整数类型，存储一定范围内正数包括0的变量类型

  | 变量名 | 描述 | 取值范围 | 占用内存 |
  | :-----: | :-----: | :-----: | :-----: |
  | `byte` | 8位无符号整数 | 0 到 255 | 1个字节 |
  | `ushort` | 16位无符号整数 | 0 到 65,535 | 2个字节 |
  | `uint` | 32位无符号整数 | 0 到 4,294,967,295 | 4个字节 |
  | `ulong` | 64位无符号整数 | 0 到 18,446,744,073,709,551,615 | 8个字节 |

  **整数用于表示没有小数部分的数值，整数类型的选择应根据所需存储的数值范围来决定，以优化内存使用**
- 浮点数类型，存储带有小数点的数值的变量类型

  | 变量名 | 描述 | 取值范围 | 占用内存 |
  | :-----: | :-----: | :-----: | :-----: |
  | `float` | 32位单精度浮点数 | ±1.5 x 10^−45 到 ±3.4 x 10^38 | 4个字节 |
  | `double` | 64位双精度浮点数 | ±5.0 x 10^−324 到 ±1.7 x 10^308 | 8个字节 |
  | `decimal` | 128位高精度十进制数 | ±1.0 x 10^−28 到 ±7.9 x 10^28 | 16个字节 |

  **浮点数用于表示带有小数部分的数值，根据编译器的不同，显示的有效数字[^有效数字]也会不同，一般会进行四舍五入处理**
- `float`类型能存储7/8位有效数字，`double`类型能存储15/17位有效数字，`decimal`类型能存储27/28位有效数字（**尽量不用**）
- C#中浮点数类型默认是`double`类型
- 在`float`类型的变量值后面需要加上f或F，表示这是一个float类型的值
- 在`decimal`类型的变量值后面需要加上m或M，表示这是一个`decimal`类型的值

- 字符类型，存储单个字符的变量类型

  | 变量名 | 描述 | 取值范围 | 占用内存 |
  | :-----: | :-----: | :-----: | :-----: |
  | `char` | 16位Unicode字符 | U+0000 到 U+FFFF | 2个字节 |

  **`char`类型的值必须使用单引号括起来**

- 布尔类型，存储存储true或false，表示真或假的逻辑值的变量类型

  | 变量名 | 描述 | 取值范围 | 占用内存 |
  | :-----: | :-----: | :-----: | :-----: |
  | `bool` | 布尔值（true或false） | true 或 false | 1个字节 |

- 字符串类型，存储一串字符的变量类型,没有上限
  
  | 变量名 | 描述 | 取值范围 | 占用内存 |
  | :-----: | :-----: | :-----: | :-----: |
  | `string` | 字符串 | 任意长度的文本 | 根据字符长度，占用内存空间不同 |

[^有效数字]:有效数字指的是一个数字中从第一个非零数字开始到最后一个数字为止的所有数字

- `string`类型的值必须使用双引号括起来
- 字符串可以是汉字、字母、数字、符号的任意组合
- 字符串是引用类型，而不是数据类型，存储的是数据的地址，而不是数据本身，其长度是可变的
- 字符串可以是空字符串（`""`）或 `null`，两者含义不同：`""` 表示引用指向一个空字符串对象，`null` 表示引用未指向任何对象（使用未检查的 `null` 可能导致 `NullReferenceException`）。
- 字符串是引用类型，而不是数据类型，存储的是数据的地址，而不是数据本身，其长度是可变的
- 字符串可以是空字符串（`""`），但不能是`null`（表示没有值）

**不同的变量，存储的范围和类型不同，本质是占用的内存空间不同**
**选择不同的数据（变量）类型装载不同的数据 节省内存空间 提高程序运行效率**
**死记硬背变量的关键字、类型、取值范围、占用内存**
**常用的只要记住这四个变量类型：整数用`int`类型，小数用`float`类型，字符串用`string`类型，逻辑判断用`bool`类型**  

#### 变量的命名规范

- 命名规则
  - 不能重名
  - 不能以数字开头
  - 不能使用程序关键字命名
  - 不能包含空格和特殊符号（下划线_除外）
  - 不要用汉字命名变量（**可以，但不推荐，会有编码问题**）
  - 变量名要有意义，见名知意，用英文（拼音）表示变量的作用
  - C#中对于大小写敏感的，是有区别的

  ```csharp
      // ✅ 正确的命名
      int age;
      int age2;
      int _privateValue;
      int studentAge;
      int 学生年龄;  // 可以但不推荐

      // ❌ 错误的命名
      int 2age;        // 不能以数字开头
      int studentAge2; // 可以，但不推荐
      int class;       // 不能使用关键字
      int student-age; // 不能使用特殊符号-
  ```

- 使用@符号创建逐字标识符

  ```csharp
      // 如果必须使用关键字作为变量名，可以在前面加@符号
      int @class = 101;      // 允许，但不推荐
      string @string = "csharp"; // 允许，但不推荐
      int @if = 10;          // 允许，但不推荐

      Console.WriteLine(@class);  // 输出：101
  ```

#### 命名方法

- 驼峰命名法（Camel Case）
**用途**：局部变量、方法参数
**规则**：第一个单词首字母小写，后续单词首字母大写
**示例**：

  ```csharp
      // 局部变量
      int studentAge = 18;
      string firstName = "Lucky";
      double totalScore = 95.5;
      bool isActive = true;

      // 方法参数
      public void SetUserInfo(string userName, int userAge)
      {
      // userName 和 userAge 使用驼峰命名法
      }
  ```

- 帕斯卡命名法（Pascal Case）
**用途**：类名、结构体、枚举、方法名、属性名、公共字段
**规则**：所有单词首字母都大写
**示例**：

  ```csharp
    // 类名
    public class StudentInfo { }
    public class UserAccount { }

    // 方法名
    public void CalculateTotal() { }
    public string GetUserName() { }

    // 属性名
    public string UserName { get; set; }
    public int StudentAge { get; set; }
  ```

- 下划线前缀命名法
**用途**：私有字段、受保护字段
**规则**：以下划线开头，后续使用驼峰命名法
**示例**：

  ```csharp
    public class Student
    {
        // 私有字段使用下划线前缀
        private string _studentName;
        private int _studentAge;
        private double _totalScore;
    }

        // 公共属性使用帕斯卡命名法
    public string StudentName 
    { 
        get { return _studentName; }  
        set { _studentName = value; }
    }
  ```

- 接口命名规范
**用途**：接口名称
**规则**：以大写字母 I 开头，后续使用帕斯卡命名法
**示例**：

  ```csharp
      // 接口命名
      public interface IStudentService { }
      public interface IDataRepository { }
      public interface IUserManager { }
  ```

- 布尔类型变量命名建议
  - 使用表达状态或问题的前缀，如：`is`、`has`、`can`、`should`
  **示例**：

  ```csharp
      bool isActive = true;      // 是否激活
      bool hasPermission = false; // 是否有权限
      bool canEdit = true;       // 是否可以编辑
      bool shouldUpdate = false; // 是否应该更新
      bool isMarried = true;     // 是否已婚
      bool hasChildren = false;  // 是否有孩子
  ```

#### 注意事项

- 使用有意义的名称

  ```csharp
      // ❌ 不好的命名（含义不清）
      int a = 18;
      string s = "Lucky";
      double d = 1000.50;
      bool b = true;
      int x, y, z;

      // ✅ 好的命名（清晰表达含义）
      int studentAge = 18;
      string userName = "Lucky";
      double accountBalance = 1000.50;
      bool isLoggedIn = true;
      int width, height, depth;
  ```

- 避免使用缩写（除非是行业通用缩写）

  ```csharp
      // ❌ 避免使用
      string usrNm = "Lucky";    // 不清楚的缩写
      int stdAge = 18;           // 不清楚的缩写

      // ✅ 推荐使用
      string userName = "Lucky";
      int studentAge = 18;

      // ✅ 可以接受的通用缩写
      string url = "https://example.com";  // URL是通用缩写 
      string html = "<div></div>";         // HTML是通用缩写
      int id = 1001;                       // ID是通用缩写
  ```

- 变量名长度要适中

  ```csharp
      // ❌ 太短，含义不清
      int x = 10;
      string n = "Lucky";

      // ❌ 太长，过于冗长
      int thisIsTheCurrentStudentAgeInYears = 18;
      string theFirstNameOfTheCurrentUserInTheSystem = "Lucky";

      // ✅ 长度适中，清晰明了
      int studentAge = 18;
      string currentUserName = "Lucky";
  ```

- 使用单复数区分单个和集合

  ```csharp
      // ✅ 单个对象使用单数
      string studentName = "Lucky";
      int studentAge = 18;

      // ✅ 集合对象使用复数
      string[] studentNames = { "Lucky", "Tom", "Jerry" };
      int[] studentAges = { 18, 19, 20 };
      List<string> userNames = new List<string>();
  ```

- 避免使用容易混淆的字符

  ```csharp
      // ❌ 避免使用（容易混淆）
      int l = 1;      // 小写L容易和数字1混淆
      int O = 0;      // 大写O容易和数字0混淆
      int I = 1;      // 大写I容易和小写l混淆

      // ✅ 使用清晰的名称
      int lineCount = 1;
      int orderNumber = 0;
      int itemIndex = 1;
  ```

- 循环变量的命名

  ```csharp
    // ✅ 简单循环：可以使用单字母
    for (int i = 0; i < 10; i++)
    {
        // i 是约定俗成的循环变量
    }

    // ✅ 嵌套循环：使用 i, j, k
    for (int i = 0; i < rows; i++)
    {
        for (int j = 0; j < cols; j++)
        {
            // i, j 是约定俗成的嵌套循环变量
        }
    }

    // ✅ 表示集合元素：使用有意义的名称
    foreach (string studentName in studentNames)
    {
        Console.WriteLine(studentName);
    }
  ```

- **命名规则总结表**

  | 类型 | 命名规范 | 示例 |
  | :-----: | :-----: | :-----: |
  | 局部变量 | 驼峰命名法 | `studentAge`, `userName` |
  | 方法参数 | 驼峰命名法 | `userName`, `userAge` |
  | 类名 | 帕斯卡命名法 | `StudentInfo`, `UserAccount` |
  | 方法名 | 帕斯卡命名法 | `GetUserName`, `CalculateTotal` |
  | 属性名 | 帕斯卡命名法 | `UserName`, `StudentAge` |
  | 接口名 | I + 帕斯卡命名法 | `IStudentService`, `IUserManager` |
  | 私有字段 | _ + 驼峰命名法 | `_studentName`, `_userAge` |
  | 布尔变量 | is/has/can + 驼峰 | `isActive`, `hasPermission` |

- **常见错误**

  ```csharp
    // ❌ 错误1：使用拼音
    string xingMing = "张三";  // 尽量不要使用拼音

    // ✅ 正确：使用英文
    string name = "张三";

    // ❌ 错误2：变量名与类型名混淆
    string String = "csharp";  // 避免这样命名
    int Int = 10;

    // ✅ 正确：使用有意义的名称
    string message = "csharp";
    int count = 10;

    string 姓名 = "Lucky";  // 尽量避免使用中文

    // ✅ 正确：遵循命名规范
    int studentAge = 18;       // 局部变量使用驼峰命名法
  ```

- **命名规则记忆口诀**

  - 变量参数驼峰式（首字母小写）
  - 类方法属性帕斯卡（首字母大写）
  - 私有字段加下划线
  - 接口命名I开头
  - 常量全部要大写
  - 名称meaningful要清晰

#### 变量的作用域

- 变量的作用域是指变量在程序中可以被访问和使用的范围

  ```csharp
      // ✅ 正确：变量在代码块内有效
      {
          int a = 10; // 变量a在这个代码块中声明
          Console.WriteLine(a); // 可以访问变量a
      } // 代码块结束，变量a的作用域结束

      // ❌ 错误：变量在代码块外不可访问
      Console.WriteLine(a); // ❌ 错误！变量a在此处不可访问
  ```

- 变量在其声明的代码块内有效
- 代码块通常由一对花括号 `{}` 定义
- 变量在代码块外部无法访问
- 变量的作用域可以**嵌套**，内层代码块**可以**访问外层代码块的变量，但外层代码块**不可以**访问内层代码块的变量
- 变量的作用域影响变量的生命周期，变量在其作用域内存在，作用域结束后变量被销毁，释放内存
- 合理管理变量的作用域，有助于提高代码的可读性和维护性，避免命名冲突和内存泄漏
- 尽量将变量的作用域限制在最小范围内，遵循“**最小权限原则**”
- **局部变量优先于全局变量**，如果局部变量和全局变量同名，优先访问局部变量
- **避免过度嵌套代码块，保持代码简洁清晰**

### 常量

### 常量是什么

- 常量是在程序运行期间其值不能被改变的量
- 使用 `const` 关键字声明常量
- 常量必须在声明时就赋值，且之后不能修改

### 常量的语法

- 声明常量的基本语法

  ```csharp
      const <变量类型> <常量名称> = <常量值>;
      //
  ```

  **示例**

  ```csharp
      const double PI = 3.14159; // 声明一个常量PI，表示圆周率
      PI = 3.14; // ❌ 错误：常量的值不能被修改
      const int MAX_STUDENTS = 50; // 声明一个常量MAX_STUDENTS，表示最大学生数
      const string SCHOOL_NAME = "北京大学"; // 声明一个常量SCHOOL_NAME，表示学校名称 
      
      Console.WriteLine("圆周率：" + PI);
      Console.WriteLine("最大学生数：" + MAX_STUDENTS);
      Console.WriteLine("学校名称：" + SCHOOL_NAME);
  ```
  
#### 常量的命名规范

- 常量名称通常使用全大写字母，单词之间用下划线分隔
- 示例：`MAX_VALUE`、`MIN_AGE`、`DEFAULT_COLOR`

### 常量与变量的区别

| 特性 | 变量 | 常量 |
| :----: | :----: | :----: |
| 关键字 | 无需特殊关键字 | 使用 `const` 关键字 |
| 值是否可修改 | 可以修改 | 不可以修改 |
| 初始化时机 | 可以先声明后赋值 | 必须在声明时赋值 |
| 使用场景 | 需要变化的数据 | 固定不变的数据 |
| 命名规范 | 驼峰命名法 | 全大写+下划线 |

**学习小结**：

- 变量用于存储可变的数据，常量用于存储不变的数据
- 选择合适的数据类型可以优化内存使用和程序性能
- 遵循命名规范可以提高代码的可读性和可维护性
- 理解变量的作用域有助于避免变量命名冲突
