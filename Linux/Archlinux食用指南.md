## 序言

Archlinux是一个轻量且自由度超高的Linux发行版，适合有一定Linux基础的用户使用

## 安装

推荐使用``archinstall``命令安装Linux，我知道很多人都说arch要学习手动安装Linux的，但手动安装Linux就像新手村里的大boss，容易劝退外乡人。与其在初期一脸茫然的敲着陌生命令，不如先跳过开始，直接进入Linux学习其他基础操作，回头等能力更强之后，再来尝试攻克这个boss

## 常用基础命令

pacman是Archlinux的包管理器，常用命令如下：

  ``` bash
    pacman -Syyu    // 更新系统
    pacman -S 软件包名    // 安装软件包
    pacman -R 软件包名    // 卸载软件包
    pacman -Ss 软件包名   // 搜索软件包

    ip a // 查看IP地址
  ```

Vim 文本编辑器基础操作
Vim 是以键盘操作为核心理念的文本编辑器，很陌生，但是绝对值得一学。

``i`` 键进入编辑模式；

``esc`` 回到普通模式；

``u`` 撤销；

``/`` 左斜杠进入搜索模式，回车跳转到搜索到的第一个，n 键跳转到搜索到的下一个，Shift+n 跳转到搜索到的上一个；

``:w`` 冒号小写 w 写入；

``:q`` 冒号小写 q 退出；

``:wq`` 冒号小写 wq 保存并退出；

``!`` 命令后加上感叹号代表强制执行。

知道这些就可以开始使用了。不习惯的话可以安装 nano。nano 的基础操作只需要记住 Ctrl+F 搜索、Ctrl+S 保存和 Ctrl+X 退出即可。你也可以选择安装 neovim，Vim 的加强版，更现代更好用。如果安装 neovim 的话后面所有 vim 命令都改成 nvim
